MK Scripts Repository

Official PixInsight Scripts by Mohammed Khalifa (mhk.astro)

1. MK Star Reduction

Performs fast, continuous star reduction using the Transfer Method. Features interactive split-view comparisons, live toggle controls, scale protection options, and a mini-map navigator for real-time visual feedback before applying changes.

2. MK Color Range Selection

An advanced interactive mask generation tool designed to precisely target and isolate specific color tones across astronomical images. Features dual side-by-side previews with independent zoom/pan, multi-point additive color sampling, sample-size averaging (1x1, 3x3, 5x5), linear auto-stretch, real-time color tolerance, Gaussian blur softening, and overall opacity controls.

3. MK Colorize By Mask

Advanced Color Tinting tool designed for astrophotography. Features a dynamic HSV Color Map, precise 0-255 RGB numeric inputs, true Luminance Protection to preserve target structures, Split-Toning for highlights vs. shadows, and multiple blend modes.

To install this repository in PixInsight:

Go to Resources > Updates > Manage Repositories and add the following URL:

https://your-repository-url-here/
